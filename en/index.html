Observation Post

tutorial · defensive security lab

A honeypot, an IDS watching it, and a dashboard showing what shows up.

This guide builds, from scratch, an isolated lab where a fake SSH/Telnet service (Cowrie) receives real, unsolicited traffic from the internet, a network sensor (Suricata) observes and classifies every packet, and a dashboard (Grafana + Loki) shows both sides of the story in real time.

about this guide

Written from a real implementation, including the configuration mistakes that showed up along the way — they get their own section (chapter 5), because they're exactly the kind of thing anyone following this path will also run into.

What you'll build

A small but complete system, with four pieces that support each other: a fake service that looks vulnerable and logs everything an attacker tries to do; a network sensor that independently observes and classifies that same traffic; a log pipeline that centralizes both; and a visual panel to follow it all live.

Who this guide is for

For anyone with some familiarity with Linux, the command line, and Docker, who wants a hands-on defensive-security project — whether as a portfolio piece, a way to learn networking, or just out of curiosity about what actually knocks on the door of a service exposed to the internet.
